# 本地预览说明

## 项目信息

- **项目名称**：《如何成为一个优雅的中世纪人》H5小游戏
- **项目类型**：mobile-static（移动端 H5 静态项目）
- **技术栈**：原生 HTML5 + CSS3 + JavaScript

## 启动方式

### 方式一：双击 bat 脚本（推荐）

双击 `zeen-tools\一键启动前端.bat`，脚本会：

1. 自动检测 Node.js 是否安装
2. 有 Node.js → 使用 `local-preview-server.js`
3. 无 Node.js → 自动回退到 PowerShell 备选服务器
4. 等待服务就绪后自动打开导航页面

### 方式二：npm 命令

```bash
npm run preview:local
```

> 注意：此方式需要已安装 Node.js。

## 停止方式

双击 `zeen-tools\一键关闭前端.bat`，脚本会：

1. 停止 Node.js 预览进程
2. 停止 PowerShell 预览进程
3. 关闭预览 cmd 窗口
4. 验证端口已释放

## 默认地址

| 页面 | 地址 |
|------|------|
| 导航页面 | http://127.0.0.1:8091/nav |
| 游戏首页 | http://127.0.0.1:8091/ |
| 游戏入口 | http://127.0.0.1:8091/game/index.html |

## 端口说明

- 默认端口：`8091`
- 如需修改，设置环境变量 `LOCAL_PREVIEW_PORT`：
  ```bash
  set LOCAL_PREVIEW_PORT=8092
  npm run preview:local
  ```

## 推荐抽查顺序

1. 导航页面 `/nav` — 查看所有可用页面和素材
2. 游戏首页 `/` — 验证游戏入口正常
3. 场景图预览 — 验证中文路径下的图片加载

## 中文路径兼容

- 所有脚本开头均设置 `chcp 65001`（UTF-8 代码页）
- HTTP 响应头统一带 `charset=utf-8`
- URL 中的中文路径通过 `decodeURIComponent` 正确解码
- PowerShell 服务器使用 `[System.Web.HttpUtility]::UrlDecode` 处理

## 手机预览

导航页右上角有「📱 手机」按钮，切换后点击游戏入口卡片会在页面下方内嵌 375×812 的 iframe 模拟手机视口，方便快速预览移动端效果。

## 这个预览服务解决了什么

1. **中文路径**：项目包含中文命名的文件夹和文件名，普通服务器可能乱码或 404
2. **路由别名**：`/` 直接映射到 `/game/index.html`，无需输入完整路径
3. **一键启停**：双击 bat 即可启动和关闭，不需要记命令行
4. **Node.js 可选**：即使没装 Node.js 也能用 PowerShell 备选方案运行
