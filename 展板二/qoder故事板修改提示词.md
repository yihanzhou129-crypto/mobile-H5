## 镜头1：传统载体 — 图书馆阅读场景

**场景描述**：用户在图书馆/书房阅读纸质书

**SVG 绘制元素**：
- **背景**：书架（3-4层，摆放书籍），窗户透入柔和光线
- **人物**：坐在书桌前，低头阅读，一只手翻书，姿态优雅
- **桌面**：摊开的书本、一杯咖啡/茶、台灯

- **台词气泡**："我希望获得纯粹的知识。"（圆角对话框，带小三角指向人物嘴部）
- **标签**："静态阅读，单向输入"（圆角标签，暖棕色底）

# 技术实现要求

1. **所有插画使用 SVG 内联绘制**，`<svg>` 标签直接嵌入 HTML
2. **不使用任何外部图片资源**（无 `<img src>`）
3. **不使用 CSS 背景图**
4. SVG 使用 `viewBox` 定义坐标系，确保缩放清晰
5. 插画尺寸：每个镜头约 200px × 150px（在 1754px 总宽度下）
6. 保持整体 A3 竖版尺寸不变（1754px × 2480px）
7. 保持其他区域（标题、服务触点矩阵、服务蓝图、设计亮点）不变，只修改故事板区域
