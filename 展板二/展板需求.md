## 配色方案

### 主色调
- **整体风格**：干净清新，优雅复古
- **主色**：莫兰迪紫色（Morandi Purple）—— 占比最大，用于标题、重点模块背景、主视觉元素
- **辅色**：莫兰迪粉色（Morandi Pink）—— 占比次于紫色，用于次要模块、点缀、装饰元素
- **底色**：白色/米白色 —— 用于大面积背景，保持版面干净
- **点缀色**：淡金色/香槟色 —— 用于装饰线条、边框、图标高光

### 具体色值参考
```
莫兰迪紫色主色：#8B7AA8 或 #9B8EC7（柔和灰紫色）
莫兰迪粉色辅色：#D4A5A5 或 #C9A9A6（柔和灰粉色）
底色：#FAF8F5 或 #FFFFFF（暖白/纯白）
点缀金：#D4AF37 或 #C9B896（淡金色）
文字深灰：#3D3D3D（主文字）
文字浅灰：#7A7A7A（次要文字）
```

### 配色分布原则
- 紫色面积 > 粉色面积
- 白色作为基底留白，避免拥挤
- 参考配色参考.jpg的渐变过渡方式，但调整为紫→粉渐变

## 艺术风格参考

### 穆夏风格（Art Nouveau）元素融入
- **装饰边框**：顶部和底部采用穆夏风格的植物藤蔓/花卉装饰边框，带有优雅的曲线和对称纹样

- **字体设计**：标题可采用带有装饰性的衬线字体或艺术字体，副标题用简洁无衬线字体
- **圆形/椭圆形装饰**：穆夏常用圆形画框、月桂叶环绕等装饰手法
- **色彩过渡**：柔和的渐变，避免强烈对比

## 展板内容结构（单页A3竖版）

### 顶部区域：展板标题区（占版面约8-10%）
- **主标题**：《如何成为一个优雅的中世纪人》——H5小游戏服务设计
- **副标题**：数字服务设计课程作业

- **装饰**：穆夏风格装饰边框，紫色渐变底色，金色点缀线条
- **项目简介**：一句话概述（约30-50字）—— 本项目以中世纪文化科普为切入点，通过H5互动小游戏形式，将传统单向知识传播转化为沉浸式人格鉴定体验，探索数字服务设计在文化传播领域的创新应用。

### 上部区域：服务触点矩阵（占版面约20-22%）
- **模块标题**：服务触点矩阵（Service Touchpoint Matrix）
- **内容展示**：
  - 表格形式呈现，横轴为"阶段触点"（认知、考虑、购买/下载、游戏体验、社交传播）
  - 纵轴为触点渠道（社交媒体、应用商店、小程序入口、游戏内界面、支付系统、客服/反馈、社区/论坛、分享功能）
  - 用色块深浅/圆点大小表示关联强度（3强/2中/1弱/0无）
  - 紫色系色阶表示强度（深紫=强，浅紫=弱，白色/灰色=无）
- **可视化增强**：
  - 表格单元格使用圆角矩形
  - 强度3用实心紫色圆点，强度2用中等紫色圆点，强度1用浅色圆点，0用虚线或空白
  - 添加图例说明
  - 可在表格旁添加小图标（如社交媒体图标、手机图标等矢量图）

### 中部区域：服务蓝图（占版面约30-35%）
- **模块标题**：服务蓝图（Service Blueprint）
- **内容展示**：
  - 横轴：服务阶段（发现 → 进入 → 沉浸 → 反馈 → 结果 → 分享）
  - 纵轴分层：
    - 第一层：前台交互层（用户可见的交互行为）
    - 第二层：后台运营层（系统/运营支撑）
    - 第三层：支持系统（技术/资源/合作支撑）
  - 用不同颜色区分三层：
    - 前台层：莫兰迪粉色背景
    - 后台层：莫兰迪紫色背景（浅色）
    - 支持系统：白色/浅灰背景，带紫色边框
  - 每个单元格内用简洁文字+小图标描述内容
  - 添加互动分界线（虚线）和可视分界线（实线）
- **可视化增强**：
  - 使用流程箭头连接各阶段
  - 添加小图标（朋友圈、扫码、手机、卡牌、分享等）
  - 重要节点用圆形标记突出
  - 整体采用横向泳道图形式

### 下部区域：用户体验对比故事板（占版面约25-28%）
- **模块标题**：用户体验对比故事板（User Experience Comparison Storyboard）

## 可视化元素要求

### 图表类
1. **服务触点矩阵**：色块热力图风格表格，圆点大小表示强度
2. **服务蓝图**：横向泳道图，分层分阶段，带流程箭头
3. **对比表格**：卡片式对比，左右分栏，图标化呈现

### 矢量图标/插画类
- 中世纪元素：城堡、羽毛笔、羊皮卷、皇冠、骑士盾牌、月桂叶
- 数字元素：手机、二维码、分享按钮、社交图标、游戏手柄
- 场景元素：图书馆、咖啡馆、书房、中世纪街道
- 人物元素：简笔风格人物（穆夏线条感），用于故事板场景
- 装饰元素：藤蔓边框、花卉纹样、圆形画框、飘带

### 字体要求
- **主标题**：优雅衬线字体（如 Noto Serif SC、Playfair Display 或类似穆夏海报字体）
- **副标题/模块标题**：无衬线字体（如 Noto Sans SC、Inter），可加粗
- **正文**：无衬线字体，小字号，清晰易读
- **英文**：搭配中文使用，保持风格一致

## 技术实现要求

### 基础要求
- 生成**单个HTML文件**，双击即可在浏览器中打开
- 使用**HTML + CSS + JavaScript**实现，可引入CDN资源（如Tailwind CSS、ECharts、html2canvas等）
- 支持**一键下载为图片**（PNG格式，A3竖版比例，300dpi等效分辨率）
- 使用 `html2canvas` 或 `dom-to-image` 库实现下载功能
- 添加明显的"下载展板"按钮

### 布局规范
- 尺寸严格按 A3 竖版：297mm × 420mm
- 等效像素（按300dpi）：约 3508px × 4961px
- 实际渲染可先用 1/2 或 1/3 分辨率，保证清晰度
- 页面 margin：上下左右各留 15-20mm 安全边距
- 出血区域：如有需要，四周留 3mm 出血

### 响应式与导出
- 浏览器中可正常缩放查看
- 导出时锁定为A3竖版比例
- 导出图片清晰，文字可读，图表不模糊

## 设计原则

1. **信息层级清晰**：标题→模块标题→内容→注释，层次分明
2. **视觉引导流畅**：从上到下，从左到右，符合阅读习惯
3. **留白适度**：避免拥挤，保持呼吸感，参考穆夏的优雅留白
4. **风格统一**：所有元素保持穆夏风格+莫兰迪配色的统一调性
5. **内容准确**：所有数据、文字必须与提供的md文件一致，不可篡改
6. **图文结合**：避免大段纯文字，尽量用图标、插画、图表可视化
7. **装饰适度**：穆夏风格边框和装饰点缀即可，不可喧宾夺主
