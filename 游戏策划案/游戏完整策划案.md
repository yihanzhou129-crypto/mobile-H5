玩家扮演一位穿越到中世纪的现代人，在一天之内经历五个典型场景，
每个场景的选择将决定你的人格倾向与优雅值。最终生成专属中世纪人格卡片。

场景一：城堡宴会厅 · 就餐之礼
══════════════════════════════════════════════════════════════════════════════

【场景描述】
你被邀请参加领主举办的盛大宴会。长桌上摆满了烤天鹅、蜜饯、香料面包和葡萄酒。
厅内烛火摇曳，乐师弹奏着鲁特琴，贵族们身着华服依次入座。
空气中弥漫着烤肉、香料和昂贵香水的混合气息。

【情节1】入座时刻
你走进宴会厅，发现座位安排有讲究。领主坐在高台主位，
宾客按身份高低排列。你注意到：

  选项A：主动走向靠近领主的高位，自信地落座
    → 优雅值：+3（展现自信，但略显冒进）
    → 场景文案：你昂首阔步走向高位，引来侧目。一位贵族低声说："这位客人倒是不客气。"

  选项B：谦逊地选择中位，观察他人后再决定
    → 优雅值：+5（知进退，懂礼仪）
    → 场景文案：你安静地站在一旁，待侍者引导后才入座。邻座的骑士向你微微点头致意。

  选项C：悄悄溜到角落的末位，观察全场
    → 优雅值：+1（低调但略显怯场）
    → 场景文案：你缩在角落，却意外发现这里的烤鹅腿没人抢，倒也不错。

  选项D：与吟游诗人一起坐在乐师旁边的即兴位置
    → 优雅值：+3（随性但有趣）
    → 场景文案：你挨着吟游诗人坐下，他立刻递来一杯麦芽酒："来，朋友，坐这儿才热闹！"

【情节2】餐前洗手
侍者端着银盆和毛巾走来，这是中世纪的洗手仪式。

  选项A：优雅地伸出双手，让侍者仔细清洗，并轻声道谢
    → 优雅值：+5（完美礼仪）
    → 场景文案："感谢您，"你微微颔首。领主投来赞许的目光。

  选项B：快速自己洗完，催促上菜
    → 优雅值：+1（急躁失礼）
    → 场景文案：你的动作太快，溅出了几滴水。邻座女士皱了皱眉。

  选项C：从怀中取出自己携带的草药香皂，边洗边介绍其功效
    → 优雅值：+3（独特但略怪）
    → 场景文案："这是薰衣草和迷迭香制成的，"你解释道。几位女士好奇地凑过来。

  选项D：用拉丁语吟诵饭前祷词，然后洗手
    → 优雅值：+5（虔诚优雅）
    → 场景文案：你的拉丁语祷词让全场安静了一瞬。领主说："这位客人颇有学识。"

【情节3】用餐时刻
主菜是烤天鹅，配着精致的银餐具。你注意到有人开始用手抓肉。

  选项A：坚持使用刀叉，切下一小块优雅地送入口中
    → 优雅值：+5（标准贵族礼仪）
    → 场景文案：你的动作如教科书般标准。对面一位老贵族满意地捋了捋胡子。

  选项B：观察领主怎么做，然后完全模仿他
    → 优雅值：+3（聪明但缺乏主见）
    → 场景文案：你像影子一样模仿领主的一举一动。他注意到了，嘴角微微上扬。

  选项C：直接用手撕下一块肉，大口吃掉，称赞厨师
    → 优雅值：+0（粗鲁但真诚）
    → 场景文案："好肉！"你大声赞叹。几个骑士哈哈大笑，但贵妇们面露嫌恶。

  选项D：只取少量食物，细细品尝，同时观察每个人的表情
    → 优雅值：+1（节制但神秘）
    → 场景文案：你吃得很少，但眼神敏锐。有人低声说："这位客人在评判我们。"

【情节4】餐后互动
宴会进入尾声，领主提议每人讲一个有趣的故事或展示一项才艺。

  选项A：讲述一个精心编排的宫廷轶事，暗含对领主的恭维
    → 优雅值：+5（政治智慧）
    → 场景文案：你的故事让领主开怀大笑，他举起酒杯："为这位机智的客人干杯！"

  选项B：朗诵一首即兴创作的短诗，赞美宴会与主人
    → 优雅值：+5（才华横溢）
    → 场景文案：你的诗句让全场鼓掌。一位贵族小姐眼含笑意地看着你。

  选项C：分享一个关于星辰与命运的哲学思考
    → 优雅值：+1（深沉但略沉闷）
    → 场景文案：有人打哈欠，但几位学者模样的客人凑过来想继续讨论。

  选项D：起身行礼，表示谦逊，将机会让给他人
    → 优雅值：+3（谦卑但平淡）
    → 场景文案："我的故事不值一提，"你说。领主点点头："谦逊也是一种美德。"

【情节1】初次邂逅
你走近时，对方转过身来。月光下，她/他的轮廓如同雕像般优美。

  选项A：行一个标准的屈膝礼/骑士礼，用拉丁语问候
    → 优雅值：+5（古典浪漫）
    → 场景文案："愿月光照亮您的道路，"你用拉丁语说道。对方眼中闪过惊喜。

  选项B：摘下一朵玫瑰，即兴创作一首短诗献上
    → 优雅值：+3（浪漫动人）
    → 场景文案："玫瑰不及您容颜的万分之一，"你吟诵道。对方脸颊微红。

  选项C：冷静地分析对方的衣着与配饰，推测其身份与喜好
    → 优雅值：+1（理性但冷淡）
    → 场景文案："您的胸针是拜占庭风格，"你说。对方愣了一下："您...很细心。"

  选项D：直接询问对方是否愿意一起散步，不谈虚礼
    → 优雅值：+3（直率但有效）
    → 场景文案："月色这么好，何必拘礼？"你伸出手。对方犹豫片刻，握住了。

【情节2】月下交谈
你们并肩走在花园小径上，对方问："你相信命中注定的爱情吗？"

  选项A：讲述骑士文学中的经典爱情故事，表达忠诚与守护的信念
    → 优雅值：+5（忠诚浪漫）
    → 场景文案："真正的爱情如骑士对领主的誓言，"你说。对方眼中泛起涟漪。

  选项B：用星象与草药学解释爱情的化学反应，神秘而迷人
    → 优雅值：+1（神秘独特）
    → 场景文案："玫瑰的芬芳会刺激心跳，"你轻声说。对方靠近了一步。

  选项C：分享一个关于自由与选择的故事，强调爱情不应被束缚
    → 优雅值：+3（自由奔放）
    → 场景文案："爱情如风，无法囚禁，"你说。对方若有所思地点头。

  选项D：引用亚里士多德的哲学，理性分析爱情的本质
    → 优雅值：+0（深刻但扫兴）
    → 场景文案："根据《尼各马可伦理学》..."你开始讲述。对方礼貌地微笑，但眼神飘向月亮。

【情节3】意外考验
突然，一位醉酒的骑士跌跌撞撞闯入花园，对你们出言不逊。

  选项A：挡在对方面前，用威严的语气命令醉酒骑士离开
    → 优雅值：+3（英勇保护）
    → 场景文案："退下，"你的声音不大但充满威严。醉酒骑士愣住，悻悻离开。

  选项B：用幽默化解尴尬，讲个笑话让醉酒骑士自己知趣离开
    → 优雅值：+3（机智化解）
    → 场景文案："朋友，您一定是把葡萄酒当水喝了，"你笑道。骑士挠挠头，不好意思地走了。

  选项C：悄悄从袖中取出镇静草药，混入一杯水中递给醉酒骑士
    → 优雅值：+5（温柔治愈）
    → 场景文案："喝点水吧，"你递过杯子。骑士喝下后渐渐平静，道谢离去。

  选项D：冷静观察局势，寻找侍者来处理，避免直接冲突
    → 优雅值：+1（谨慎但被动）
    → 场景文案：你默默退后，向远处的侍者使眼色。侍者迅速赶来带走了骑士。

【情节4】离别时刻
夜深了，对方必须返回城堡。临别前，她/他期待地看着你。

  选项A：亲吻对方的手背，承诺明日再见
    → 优雅值：+5（经典浪漫）
    → 场景文案：你的吻轻柔而短暂。对方轻声说："我等着您。"

  选项B：将玫瑰编成花环，戴在对方头上作为纪念
    → 优雅值：+3（诗意浪漫）
    → 场景文案："这样，月亮会记住您今晚的美，"你说。对方捧着花环，笑容如花。

  选项C：赠送一枚随身携带的护身符，祝福对方平安
    → 优雅值：+3（深情内敛）
    → 场景文案："这是圣克里斯托弗的护身符，"你说。对方珍重地握在手心。

    → 优雅值：+1（实用但功利）

══════════════════════════════════════════════════════════════════════════════

【场景描述】
次日清晨，号角声唤醒了城堡。今天是年度比武大会的日子，
训练场上尘土飞扬，骑士们正在热身。你也被邀请参加或观礼。
空气中弥漫着马匹、皮革和金属的气息。

【情节1】赛前准备
领主询问你是否愿意参加比武，或作为顾问/观礼者。

  选项A：毫不犹豫地接受挑战，选择最重的长剑和最好的铠甲
    → 优雅值：+3（英勇自信）
    → 场景文案："我接受挑战！"你的声音回荡在训练场。骑士们欢呼起来。

  选项B：婉拒参赛，但提出可以为骑士们提供战术建议
    → 优雅值：+1（智慧辅助）
    → 场景文案："我的剑术不如我的头脑，"你说。领主点头："那就做我的军师。"

  选项C：表示愿意为受伤的骑士提供草药治疗，在医疗帐篷待命
    → 优雅值：+5（慈悲关怀）
    → 场景文案：你开始在帐篷里研磨草药。一位骑士感激地说："有您在，我们放心多了。"

  选项D：提议用诗歌和音乐为比武大会助兴，不做武力参与
    → 优雅值：+3（文艺参与）
    → 场景文案：你拨动鲁特琴，唱起古老的歌谣。骑士们跟着节奏挥舞长剑。

【情节2】比武时刻
比武开始，你注意到一位年轻骑士明显处于下风，即将被击败。

  选项A：大声呼喊战术指导，帮助年轻骑士扭转局势
    → 优雅值：+3（场外指导）
    → 场景文案："向左闪！刺他的腋下！"你的喊声让年轻骑士精神一振，反败为胜。

  选项B：冲入场地，用身体挡住攻击，宣布比赛暂停
    → 优雅值：+0（冲动但勇敢）
    → 场景文案：你挡在两人之间。全场哗然。领主皱眉："这是违规的！"

  选项C：悄悄向裁判示意，让裁判以"不公平优势"为由暂停比赛
    → 优雅值：+1（政治手段）
    → 场景文案：裁判收到你的暗示，吹响了哨子。年轻骑士得以喘息调整。

  选项D：用一首激励的战歌鼓舞年轻骑士，激发他的斗志
    → 优雅值：+5（精神鼓舞）
    → 场景文案：你的歌声如号角般嘹亮。年轻骑士眼中燃起火焰，奋力反击。

【情节3】胜负之后
年轻骑士最终获胜，但对手受了轻伤。胜者骄傲地举起双手。

  选项A：上前祝贺胜者，同时关心败者的伤势，展现骑士风度
    → 优雅值：+5（完美骑士精神）
    → 场景文案："胜利属于勇者，但荣誉属于所有人，"你说。全场为你鼓掌。

  选项B：为败者包扎伤口，用草药缓解他的疼痛
    → 优雅值：+5（慈悲为怀）
    → 场景文案：败者感激地握住你的手："您比胜利者更让我难忘。"

  选项C：向胜者提出挑战，认为真正的强者不应欺负弱者
    → 优雅值：+0（叛逆但欠妥）
    → 场景文案：胜者愣住，然后大笑："好！明天我接受您的挑战！"

  选项D：记录这场比赛的细节，准备写成诗歌或故事流传
    → 优雅值：+3（文艺记录）
    → 场景文案：你掏出羊皮纸奋笔疾书。一位老骑士说："您会让这场比武永垂不朽。"

【情节4】骑士誓言
领主邀请所有参与者宣读骑士誓言。

  选项A：庄严宣誓，承诺守护弱者、忠于领主、维护荣誉
    → 优雅值：+5（庄严神圣）
    → 场景文案：你的誓言字字铿锵。领主说："这才是真正的骑士。"

  选项B：宣誓但加入自己的理解，强调智慧与仁慈同样重要
    → 优雅值：+3（独特诠释）
    → 场景文案："我誓以智慧引导剑锋，以仁慈衡量力量，"你说。众人若有所思。

  选项C：安静地站在一旁，为宣誓者祈祷祝福
    → 优雅值：+3（虔诚祝福）
    → 场景文案：你低声念诵祷词。一位骑士感受到你的祝福，向你点头致意。

  选项D：用诗歌的形式重新诠释誓言，让所有人都能记住
    → 优雅值：+3（诗意创新）
    → 场景文案：你的诗歌版誓言朗朗上口，骑士们开始齐声吟诵。

【场景描述】

【情节1】家务管理
领主夫人请你帮忙处理一件家务事：仓库的粮食分配。
今年收成不好，需要精打细算。

  选项A：制定详细的分配计划，按家庭人口和劳动量精确分配
    → 优雅值：+3（精明管理）

  选项B：建议优先照顾老人、孩子和病人，再考虑其他人
    → 优雅值：+5（仁慈优先）
    → 场景文案："弱者应先得到庇护，"你说。夫人感动地握住你的手。

  选项C：提议用一部分粮食酿酒，既能保存又能提升士气
    → 优雅值：+1（实用但冒险）
    → 场景文案："啤酒是最好的 morale booster，"你笑道。夫人犹豫后同意了。

  选项D：建议举办一次丰收感恩宴，用仪式凝聚人心
    → 优雅值：+3（仪式感）
    → 场景文案："感恩会让人们珍惜每一粒粮食，"你说。夫人点头："这主意很高明。"

【情节2】子女教育
领主的儿子调皮捣蛋，夫人请教你应该如何管教。

  选项A：建议送他去骑士训练营，用纪律和荣誉塑造品格
    → 优雅值：+3（传统教育）
    → 场景文案："钢铁需要烈火锻造，"你说。夫人担忧但同意。

  选项B：提议教他读书、写字和天文，培养智慧与好奇心
    → 优雅值：+5（智慧启蒙）
    → 场景文案："知识是最好的武器，"你说。男孩眼睛一亮："我能学星星吗？"

  选项C：建议让他跟随吟游诗人学习音乐和故事，释放天性
    → 优雅值：+3（天性释放）
    → 场景文案："每个孩子心中都有一首歌，"你说。男孩立刻跑去拿鲁特琴。

  选项D：教他园艺和草药知识，让他在劳作中学会耐心
    → 优雅值：+3（自然教育）
    → 场景文案："种下一颗种子，等待它发芽，这是最好的耐心课，"你说。

【情节3】伴侣相处
领主与夫人似乎有些误会，气氛微妙。你被邀请共进晚餐，
发现两人交流甚少。

  选项A：在餐桌上巧妙地引导话题，让两人回忆起相识的美好
    → 优雅值：+5（情商高超）
    → 场景文案："我听说二位是在春天的樱花树下相遇的？"你问道。两人对视，嘴角浮现微笑。

  选项B：提议一起散步，让自然环境和独处时间修复关系
    → 优雅值：+3（温柔撮合）
    → 场景文案："花园的玫瑰开了，一起去看看？"你建议。两人默默起身，并肩走出。

  选项C：赠送一本关于夫妻相处的古典著作，含蓄地提供建议
    → 优雅值：+1（理性但冷淡）
    → 场景文案："这是奥维德的《爱的艺术》，"你说。领主接过书，表情复杂。

  选项D：用一首关于爱情与谅解的诗歌，在晚餐后为他们弹唱
    → 优雅值：+3（艺术疗愈）
    → 场景文案：你的歌声如泣如诉。夫人悄悄拭去眼角的泪水，领主握住了她的手。

【情节4】家庭仪式
夜幕降临，全家准备进行睡前的家庭祈祷。

  选项A：带领全家用拉丁语念诵祷词，庄严而温馨
    → 优雅值：+5（虔诚庄严）
    → 场景文案：你的拉丁语祷词让整个家庭沉浸在神圣的氛围中。孩子们安静而专注。

  选项B：分享一个关于感恩与珍惜的小故事，温暖人心
    → 优雅值：+3（温馨动人）
    → 场景文案："从前，有一个骑士，他拥有一切却不懂珍惜..."你的故事让孩子们依偎在父母身边。

  选项C：教大家一首简单的感恩歌曲，全家一起合唱
    → 优雅值：+3（欢乐和谐）
    → 场景文案：全家人的歌声虽不专业，但充满真挚。连管家都跟着哼唱起来。

  选项D：建议每个人说出今天最感恩的一件事，增进交流
    → 优雅值：+3（理性温馨）
    → 场景文案："我今天最感恩的是..."每个人轮流分享。夫人说："感恩有客人让我们团聚。"

【场景描述】
最后一天，国王突然驾临城堡，召开紧急议事会。
大厅内气氛凝重，贵族、骑士、学者、商人齐聚一堂。
国王提出一个难题：邻国的入侵威胁，以及国内粮食短缺的双重危机。
所有人的目光都投向了你——这位近日来展现非凡智慧的神秘客人。

【情节1】危机应对
国王询问你的建议：是先解决外患，还是先安抚民心？

  选项A：主张先巩固国防，召集骑士，展示武力威慑敌人
    → 优雅值：+3（强硬果断）
    → 场景文案："剑锋是最好的外交语言，"你说。骑士们拔剑响应，国王微微点头。

  选项B：建议先开仓放粮，稳定民心，再图外交解决
    → 优雅值：+5（仁慈治国）
    → 场景文案："饥饿的人民不会为国王而战，"你说。国王沉思后下令开仓。

  选项C：提议派遣间谍和商人潜入敌国，用贸易和情报瓦解对方
    → 优雅值：+5（谋略深远）
    → 场景文案："让敌人的钱包先投降，"你微笑道。国王眼中闪过精光。

  选项D：建议举办一场盛大的和平宴会，邀请敌国使节，用文化感化
    → 优雅值：+3（文化外交）
    → 场景文案："没有什么敌人是一顿好饭和一首歌化解不了的，"你说。国王大笑："有趣！"

【情节2】权力平衡
一位大贵族暗中质疑国王的决定，气氛剑拔弩张。

  选项A：站出来公开支持国王，用逻辑和情感说服质疑者
    → 优雅值：+5（政治智慧）
    → 场景文案："质疑是智慧，但团结是力量，"你的话语让质疑者哑口无言。

  选项B：私下与质疑者交谈，用利益交换换取他的支持
    → 优雅值：+1（政治交易）
    → 场景文案："您会得到新的贸易路线，"你低声说。质疑者眼中闪过贪婪，点头同意。

  选项C：用一段关于团结的历史典故，委婉地提醒众人内斗的危害
    → 优雅值：+3（智慧劝诫）
    → 场景文案："罗马的衰落始于内斗，"你说。质疑者沉默，缓缓坐下。

  选项D：提议用一场骑士决斗来裁决分歧，让上帝决定对错
    → 优雅值：+0（传统但冒险）
    → 场景文案："让上帝的旨意通过剑锋显现，"你说。国王摇头："太危险了。"

【情节3】外交礼仪
敌国使节突然到达，国王需要有人接待。

  选项A：以最高规格接待，展示王国的财富与文化底蕴
    → 优雅值：+5（奢华外交）
    → 场景文案：宴会上，使节被王国的繁华震撼。"您的国家比传说中更伟大，"他说。

  选项B：用真诚和谦逊打动使节，展现王国的道德力量
    → 优雅值：+3（道德外交）
    → 场景文案："我们不求征服，只求和平共处，"你说。使节深受触动。

  选项C：用智慧和学识与使节辩论，让他认识到战争的愚蠢
    → 优雅值：+3（智慧外交）
    → 场景文案："战争的成本是和平的十倍，"你的数据让使节无法反驳。

  选项D：用音乐和诗歌营造轻松氛围，在欢笑中化解敌意
    → 优雅值：+3（文化外交）
    → 场景文案：一曲欢快的歌谣后，使节举杯："为友谊干杯！"

【情节4】最终抉择
国王决定赐予你一片土地和封号，但你必须选择自己的道路。

  选项A：接受封号，承诺成为国王最忠诚的顾问与守护者
    → 优雅值：+5（功成名就）
    → 场景文案：你单膝跪地，接受国王的佩剑。"从此，您就是王国最优雅的贵族。"

  选项B：婉拒土地，请求建立一座图书馆和修道院，传播知识
    → 优雅值：+5（淡泊名利）
    → 场景文案："知识比黄金更珍贵，"你说。国王感动："您是真正的贤者。"

  选项C：请求成为王国的游吟大使，用艺术连接各国
    → 优雅值：+3（自由灵魂）
    → 场景文案："我的琴就是我的剑，"你说。国王大笑："去吧，用音乐征服世界！"

  选项D：请求在边境建立草药园和医院，治愈战争创伤
    → 优雅值：+5（慈悲济世）
    → 场景文案："让我治愈这片土地，"你说。国王郑重地点头。

  选项E：请求建立炼金实验室和贸易站，探索未知与财富
    → 优雅值：+1（探索未知）
    → 场景文案："真理与黄金同在，"你说。国王好奇："您是个有趣的人。"
